> 접기와 절단면 · 겹침과 끼움 · 원본의 무게중심 · 실제 종이 섬유 · 읽히는 종이 문자

XXD Panel 014는 Codex와 호환 에이전트를 위한 이미지 생성 Skill입니다. 정체성, 실루엣, 자세와 서사 관계를 보존한 뒤 접기, 절단면, 겹침, 끼움, 가림, 종이 조각의 결합으로 원본이 한눈에 읽히는 현대 종이 조각을 만듭니다.

구도는 고정 중앙이 아니라 사진의 무게중심, 윤곽 흐름, 질량 비율과 동작 방향을 따릅니다. 원본 색은 조화롭고 선명한 종이 색군으로 바뀌며, 부드러운 확산광이 섬유, 접힌 자국, 절단면, 두께, 층 간격과 자연 그림자를 실제처럼 보여 줍니다. 주 제목도 접거나 오린 종이로 만들어 공간 구조에 참여합니다.

## 왜 014이 필요한가요

일반적인 ‘종이접기 스타일’은 로우폴리 CG, 어린이 공예, 플라스틱 3D, 평균 대칭 또는 어떤 사진에도 붙일 수 있는 종이학과 종이꽃으로 쉽게 무너집니다.

014은 순서를 뒤집습니다.

```text
정체성／실루엣／자세／관계 고정 → 무게중심, 질량, 동작 방향 읽기 → 원본 고유 접기 지도 만들기 → 접힌 면, 절단면, 겹침, 끼움, 여백 형태로 주제 요약 → 위계, 축, 삼각 안정, 대각 긴장, 가림으로 하나의 초점 구성 → 원본 종이 색군으로 번역 → 읽히는 제목을 종이 공간 구조로 만들기
```

무관한 사진으로 바꿔도 조각의 실루엣, 접기 지도, 무게 배분, 종이 색군, 보조 종이 조각과 문자 관계가 거의 그대로 성립한다면 014가 아닙니다.

## 014의 시각적 원칙

- **원본 정체성:** 최소 세 가지 고유 단서로 실루엣, 자세, 동작, 구조, 크기, 여백 형태와 관계를 보존합니다.
- **실제 종이 구조:** 접기, 절단면, 겹침, 끼움, 교차, 가림, 결합이 물리적으로 설득력 있고 매끈한 로우폴리 CG가 아닙니다.
- **원본 주도 구도:** 무게중심, 윤곽, 질량, 방향에 따라 비대칭 배치, 부분 크롭, 연장, 부유를 정하며 기계적 중앙과 평균 대칭을 피합니다.
- **하나의 초점:** 위계, 크기 대비, 축, 삼각 안정, 대각 긴장, 양·음 공간이 한 주 조각을 지지하고 보조 종이는 경쟁하지 않습니다.
- **원본 종이 색군:** 동색 명암, 인접색, 소량의 대비색으로 면과 깊이를 나누고 밝은 배경과 넓은 여백을 유지합니다.
- **실제 재질:** 부드러운 확산광이 섬유, 접힌 자국, 절단면, 두께, 층 분리와 자연 그림자를 분명히 보여 줍니다.
- **종이 문자:** 짧은 단어나 제목이 감싸기, 축 연장, 윤곽 밀착, 받치기, 끼워 넣기, 겹침, 부유로 읽히는 공간 구조가 됩니다.

## 예시 · 곧 추가됩니다

저장소에는 향후 예시를 위한 [`assets/examples/`](assets/examples/) 폴더가 마련되어 있습니다. 프로젝트 작성자가 확인한 014 완성작만 추가하며, 그전에는 다른 스타일의 게시물이나 이미지를 자리표시자로 쓰지 않습니다.

향후 예시는 014의 적용 범위만 보여 줍니다. 예시의 주제, 은유, 팔레트, 문구, 화면 비율은 생성 참조나 기본값이 되지 않습니다.

## 네 가지 출력, 하나의 종이 조각 논리

네 가지 모드는 하나만 또는 여러 개를 함께 선택할 수 있습니다. `1`, `1+3`, `1、2、4`, `전체`라고 답하면 Skill이 중복을 제거하고 1→4 순서로 실행합니다. 각 모드는 별도 작업 폴더에 독립적으로 출력되며 한 장의 모음 이미지로 합치지 않습니다. `전체`는 원본 한 장당 PNG 7개(일반 모드 각 1개＋배경화면 4개)를 만듭니다. 크기는 모드별로 표시해 같은 답변에서 지정할 수 있고, 지정하지 않은 일반 모드는 원본에 맞춥니다. 문구는 기본적으로 선택한 모드가 공유하며 모드별 지정도 가능합니다.

| 모드 | 크기 규칙 | 결과물 |
| --- | --- | --- |
| `top-bottom` | 원본 적응형 | 위에는 전체 원본, 아래에는 014 현대 종이접기 조각. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `left-right` | 원본 적응형 | 왼쪽에는 전체 원본, 오른쪽에는 014 현대 종이접기 조각. 두 패널이 원본 크기를 유지하며 정확히 50/50 |
| `design-only` | 원본 적응형 | 원본 사진은 보이지 않고 변환 디자인만 표시. 원본 비율과 크기 유지 |
| `wallpaper-pack` | 기기별 네 가지 크기 | 휴대전화, iPad, 데스크톱, 어린이용 스마트워치 PNG 개별 출력 |

정확한 사용자 픽셀 > 지정 비율 또는 용도 > 일반 모드의 원본 적응형 순서입니다. 원본 `014.md`의 3:4는 초기 창작 캔버스일 뿐 현재 Skill의 숨은 기본값이 아닙니다.

짝을 이루는 모드의 사진은 절제된 색 보정과 필요한 환경 확장만 적용해 사실성을 지킵니다. 디자인 단독과 배경화면은 사진을 근거로 사용하지만 원본을 보여 주지 않습니다.

### 배경화면 세트: 연결형 또는 독립형

배경화면에는 숨은 기본 크기가 없습니다. 일반 프리셋은 휴대전화 `1440×3200`, iPad `2048×2732`, 데스크톱 `3840×2160`, 스마트워치 `1024×1024`이며 기기별 사용자 지정 크기도 가능합니다.

- **연결형 세트(권장):** 먼저 iPad 기준 작품을 생성하고 승인합니다. 나머지 세 기기는 원본 사진＋동일한 기준 작품을 참조해 각 화면에 맞게 새로 구성합니다.
- **독립형 네 작품:** 각 기기는 원본 사진만 참조하며 조각 크기, 비대칭 위치, 접힌 면 리듬, 종이 색군, 보조 종이와 문자 관계를 각각 탐색합니다.

연결형은 크롭이 아닙니다. 네 장 모두 따로 생성하고 구성하며 검수하고, iPad→휴대전화→데스크톱→스마트워치 순으로 참조를 이어 붙이지 않습니다.

## 문구 자체가 종이 공간 구조입니다

생성 전에 자동 문구, 사용자 지정 문구, 무문자 출력 중 하나를 선택합니다. 문구가 있으면 대상 언어나 지역도 지정합니다.

자동 문구는 주제의 정체성, 테마, 동작, 감정, 관계 또는 근거 있는 상징에서 짧은 단어나 제목을 만들고 필요할 때만 소수의 번호, 장소, 상태어, 미세 주석을 더합니다.

장소, 날짜, 출처와 사실 번호는 사용자 제공이나 신뢰할 수 있는 근거가 필요하며 꾸며 내지 않습니다. 주 제목은 주제에 맞춰 형태를 감싸고, 축을 따라 뻗고, 윤곽에 붙고, 위아래를 받치고, 층 사이로 끼고, 깊이에서 겹치거나 여백에 떠서 조각에 참여합니다.

사용자가 완성 문구를 주면 그대로 유지합니다. 방향이나 수정 가능한 초안일 때만 대상 독자, 목적, 필수 단어, 어조, 함의를 보존하며 다듬습니다.

언어는 명령문의 언어가 아니라 의도한 독자를 따릅니다.

```text
목표 시장 또는 독자 > 지정한 결과물 언어 > 방향 지시 언어; 모두 불분명하면 생성 전에 질문
```

일본판은 자연스러운 현대 일본어를, 한국 독자용은 자연스러운 현대 한국어와 정확한 띄어쓰기를, 영국판은 영국 영어를 사용합니다. 아랍어판은 기본적으로 자연스러운 현대 표준 아랍어와 올바른 오른쪽에서 왼쪽으로 흐르는 구성을 사용합니다. 외모, 옷, 풍경, 간판으로 국적을 추측하지 않으며 가짜 외국어 문자를 쓰지 않습니다.

## 정확한 기하는 코드가, 작품은 이미지 생성이 맡습니다

이미지 모델이 원본에 묶인 종이 주제, 접힌 면, 절단면, 겹침, 끼움, 종이 색군, 촉각적 빛과 종이 문자를 만듭니다. `scripts/compose_panel.py`는 캔버스 계획, 정확한 50/50 래스터 합성, 최종 크기와 검수만 수행하며 프로그램 그림으로 결과물을 위조하지 않습니다.

```bash
python3 scripts/compose_panel.py --plan --layout top-bottom --source photo.png
python3 scripts/compose_panel.py --plan --layout left-right --size 2560x1440
python3 scripts/compose_panel.py --audit result.png --layout design-only --size 2048x2048
```

정확한 상하 캔버스는 전체 높이, 좌우 캔버스는 전체 너비가 짝수여야 합니다. 요청 픽셀을 몰래 변경하지 않습니다.

## 경계와 신뢰

- 각 사진은 독립된 작업 안에서만 사용하며 다른 입력, 과거 결과, 예시의 피사체, 색, 문구, 구도를 빌리지 않습니다.
- 호출할 때마다 새 작업 폴더를 만들고 원본과 조건이 같아도 새로 생성합니다.
- 결과물은 PNG 비트맵이며 SVG, HTML, Canvas, 프로그램 드로잉 대체물이 아닙니다.
- 설정된 비트맵 브리지는 정제된 상태만 출력하며 공급자, 엔드포인트, 헤더, 인증 정보, 프롬프트, 응답 본문을 노출하지 않습니다.
- 선택한 일반 모드마다 파일 1개를 반환하고, `wallpaper-pack`을 선택하면 독립 배경화면 4개를 추가합니다. `전체`는 원본 한 장당 PNG 7개를 네 개의 동급 모드 폴더에 저장하며 모음 이미지로 합치지 않습니다.

로컬 합성에는 Python 3와 Pillow가 필요합니다. 안전한 비트맵 브리지는 Python 3.11 이상의 `tomllib`을 사용합니다. 이미지 생성에는 내장 래스터 기능이 있는 호스트 에이전트 또는 이미 설정된 호환 경로가 필요합니다.
